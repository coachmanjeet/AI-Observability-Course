# AI Agent Observability & Governance in Practice

Course and book materials for *AI Agent Observability & Governance in Practice*: tracing, identity, policy and metering for enterprise agent fleets.

| Folder | What it holds |
|---|---|
| [`agent-observability-book/`](agent-observability-book/) | Companion code for the book: the Agent Receipt spec, schemas and validator, the maturity self-assessment, and every print figure as code |

The running example is Pronto, the online grocery store from [*AI Agent Evals in Practice*](https://github.com/coachmanjeet/AI-Agent-Evals-Course). Book 1's eval suite decides whether an agent ships. This repo shows how to discover, govern and observe a whole fleet of agents once they ship.
